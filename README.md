# Algorithms On Linear Array of Integers
Includes the following algorithms that can be executed on the linear array:-
--
- Find Largest Integer
- Traverse each Element
- Insert New Element
- Remove an Element
- Bubble Sort the Array
- Linear Search an Element
- Binary Search an Element

> Also, I have looped it so we can run different algorithms without having to run it again and again.
> Includes a small help feature (can be accessed by typing 'h') that displays basically the same thing that is displayed in the beginning.
> Type 'e' to exit the program.
